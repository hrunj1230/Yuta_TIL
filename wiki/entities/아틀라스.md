# 아틀라스

## 설명
아틀라스는 흩어진 레포지토리 100개를 하나의 코드 지도로 만드는 프로젝트 또는 시스템으로 설명된다. 여러 저장소에 분산된 코드와 의존성을 사람이 직접 탐색하지 않아도 전체 구조를 파악하도록 돕는 목적을 가진다. 예시로 ‘선물하기 메뉴 목록’이 어떻게 만들어지는지 질문하면, [[concepts/에이전트|에이전트]]가 관련 API 스펙과 실제 흐름을 분석해 설명하는 상황이 제시된다. 아틀라스는 [[entities/llm-wiki|llm wiki]] 및 [[concepts/MCP|MCP]]와 결합될 때 코드베이스 이해, 업무 문의 대응, 문서 탐색 비용 감소에 기여하는 프로젝트로 볼 수 있다.
