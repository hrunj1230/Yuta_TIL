# boost-mcp

## 설명
boost-mcp는 MCP로 연결해 업무를 대신 수행하거나 요약하는 데 사용되는 도구로 언급된다. 소스에서는 [[entities/boost-kb|boost-kb]]와 함께 등장하며, 에이전트가 외부 시스템과 연결되어 조직의 업무 데이터를 다루는 사례로 보인다. 이름상 [[concepts/mcp|MCP]] 기반 연결 계층 또는 MCP 서버 역할을 하는 제품·도구일 가능성이 높다. [[concepts/에이전트|에이전트]]가 외부 업무 시스템에 접근해 요약, 조회, 자동화를 수행하게 하는 구체적 사례로서 중요하다.
