# langfuse

## 설명
langfuse는 소스에서 [[concepts/에이전트-평가-루프|에이전트 평가 루프]]와 함께 언급된 제품 또는 플랫폼이다. 이 도구는 [[concepts/에이전트|에이전트]]의 동작을 관찰하고, 결과를 평가하며, 피드백 기반 개선 사이클을 만드는 용도로 연결된다. [[entities/troubleshooter-mcp|troubleshooter-mcp]]처럼 장애 분석이나 자동 PR 생성 등 실제 업무를 수행하는 에이전트에서는 결과 품질과 추론 과정을 추적하는 체계가 중요하다. langfuse는 이러한 평가 루프를 운영하기 위한 관찰성, 평가, 개선 흐름을 지원하는 도구로 제시된다.
