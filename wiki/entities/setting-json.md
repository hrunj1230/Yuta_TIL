# setting.json

## 설명
setting.json은 소스에서 Hooks가 이벤트 발생을 기준으로 동작하도록 설정하는 파일로 언급된다. 에이전트 작업 환경에서 특정 이벤트가 발생했을 때 자동 실행 규칙을 정의하는 구성 파일의 역할을 한다. 예를 들어 코드 수정 후 자동 줄맞춤 같은 작업은 [[concepts/자동호출|자동호출]]과 설정 파일의 조합으로 구현될 수 있다. 소스의 맥락에서는 수동 명령보다 자동화된 반응형 [[concepts/워크-플로우|워크 플로우]]를 가능하게 하는 기반 요소로 볼 수 있다.
