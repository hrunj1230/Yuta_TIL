# troubleshooter - mcp

## 설명
troubleshooter - mcp는 에러 알림을 받아 장애를 분석하고 진단 리포트를 생성하며 코드 수정 PR까지 이어지는 [[concepts/mcp|MCP]] 기반 도구로 언급된다. 이 도구는 장애 대응 자동화의 구체적인 흐름을 보여 주며, [[concepts/에이전트|에이전트]]가 외부 시스템과 연결되어 문제 탐지, 원인 분석, 수정 제안, PR 생성까지 수행하는 사례로 설명된다. 소스 맥락에서는 단순한 설명형 도구가 아니라 운영 업무에 직접 개입하는 자동화 제품으로 제시된다. [[entities/langfuse|langfuse]]와 함께 관찰, 진단, 평가 흐름을 구성할 수 있는 관련 엔티티로 볼 수 있다. 또한 [[concepts/에이전트-평가-루프|에이전트 평가 루프]]와 연결되어 에이전트 기반 장애 대응의 품질을 점검하는 맥락에서 이해될 수 있다.
