# 진단 리포트

## 정의
진단 리포트는 에러 알림이나 장애 발생 이후, 장애의 원인과 현재 상태, 후속 조치 방향을 정리한 분석 결과물이다. 소스에서는 [[entities/troubleshooter-mcp|troubleshooter-mcp]] 계열 MCP가 장애를 분석한 뒤 작성하며, 이후 [[concepts/git-pr|git-pr]]을 통한 코드 수정 흐름으로 연결되는 중간 산출물로 제시된다.

## 주요 특징
- 에러 알림 이후의 장애 분석 결과를 구조화한 보고서이다.
- 문제 원인, 영향 범위, 현재 상태, 가능한 조치 방향을 정리한다.
- 운영 알림을 단순 요약하는 수준을 넘어 원인 분석과 후속 수정 작업을 연결한다.
- [[concepts/에이전트|에이전트]]가 운영 문제를 분석하고 개발 작업으로 전환할 수 있음을 보여준다.
- 코드 수정 [[concepts/git-pr|git-pr]] 생성 전, 사람의 판단과 검토를 돕는 중간 산출물로 기능한다.

## 응용
진단 리포트는 개발 및 운영 자동화에서 장애 대응 절차를 체계화하는 데 사용된다. 예를 들어 에러 알림이 발생하면 [[entities/troubleshooter-mcp|troubleshooter-mcp]]가 로그와 상태를 분석하고, 원인과 조치 방향을 담은 진단 리포트를 생성한 뒤, 필요한 경우 수정 작업을 [[concepts/git-pr|git-pr]]로 이어갈 수 있다. 이를 통해 운영자는 문제 상황을 빠르게 이해하고, 개발자는 수정 작업의 맥락을 명확히 파악할 수 있다.
