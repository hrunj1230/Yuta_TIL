# 프롬프트

## 정의
프롬프트는 사용자의 대화나 입력을 에이전트가 수행할 지침으로 구조화하는 출발점이다. 소스에서는 프롬프트가 [[entities/rules-md|rules-md]]와 [[entities/claude-md|claude-md]] 같은 지침 파일을 거쳐 작업 흐름, 도구 사용, 외부 연결로 확장되는 설계 단위로 제시된다.

## 주요 특징
- 사용자의 의도와 요청을 에이전트가 실행 가능한 지침으로 바꾼다.
- 에이전트 작업 흐름의 첫 단계로 기능한다.
- [[entities/rules-md|rules-md]], [[entities/claude-md|claude-md]] 같은 지침 파일과 연결될 수 있다.
- [[concepts/skills|skills]], [[concepts/hooks|hooks]], [[concepts/mcp|mcp]]로 확장되어 실행 방식과 외부 연동을 유도한다.
- 단순한 질문이 아니라 에이전트의 역할, 절차, 도구 사용 방식을 설계하는 단위다.

## 응용
- [[concepts/에이전트|에이전트]]에게 역할과 목표를 지정하는 초기 지침 작성
- 반복 가능한 작업을 [[concepts/워크-플로우|워크 플로우]]로 정리하기 위한 입력 설계
- 특정 [[concepts/도구|도구]] 사용을 유도하는 실행 조건 정의
- 프로젝트별 규칙을 [[entities/rules-md|rules-md]] 또는 [[entities/claude-md|claude-md]]에 반영하는 지침 구조화
- [[concepts/skills|skills]], [[concepts/hooks|hooks]], [[concepts/mcp|mcp]]와 연결되는 에이전트 실행 환경 설계
