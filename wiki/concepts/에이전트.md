# 에이전트

## 정의
에이전트는 특정 역할과 목표에 맞춰 대화, 지침, 워크플로우, 도구를 연결하고 반복적으로 작업을 수행하는 실행 주체이다. 단순 질의응답형 챗봇을 넘어 외부 시스템과 연동하고, 추론과 실행 루프를 통해 코드 분석, 업무 자동화, 장애 대응, 코드 수정 같은 복합 작업을 수행하는 시스템으로 다뤄진다.

## 주요 특징
- 특정 역할이나 목표 조건에 특화되어 동작한다.
- 대화, 지침, 워크플로우, 도구를 연결해 실제 작업을 수행한다.
- [[concepts/mcp|MCP]]를 통해 외부 시스템이나 데이터 소스와 연동될 수 있다.
- [[concepts/skills|skills]], [[concepts/hooks|Hooks]], [[concepts/plugins|plugins]]와 결합해 기능을 확장한다.
- 단발성 응답이 아니라 목표 달성을 위한 반복 실행 루프를 수행한다.
- 추론 강도, 실행 조건, 품질 기준을 설정해 운영할 수 있다.
- [[concepts/에이전트-평가-루프|에이전트 평가 루프]]를 통해 결과 품질과 안정성을 관리해야 한다.

## 응용
- 코드베이스의 흐름과 의존성을 분석한다.
- 업무 내용이나 운영 상황을 요약한다.
- 장애 원인을 분석하고 대응 절차를 제안한다.
- 코드 수정안을 만들고 PR 생성을 자동화한다.
- 외부 도구와 연결해 반복적인 운영 업무를 자동화한다.
- 지식베이스, 관측 도구, 코드 분석 도구와 결합해 개발 및 운영 지원 시스템을 구성한다.
