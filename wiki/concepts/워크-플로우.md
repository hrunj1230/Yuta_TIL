# 워크 플로우

## 정의
워크 플로우는 사용자의 요청이나 대화형 지침을 체계적인 절차로 변환하고, 필요한 기능과 외부 도구를 순서대로 실행하도록 구성하는 작업 흐름이다. 에이전트 환경에서는 프롬프트가 지침 파일을 거쳐 스킬, 훅, 외부 프로토콜로 연결되는 중간 실행 구조를 의미한다.

## 주요 특징
- 사용자의 단발성 요청을 반복 가능한 절차로 구조화한다.
- 지침, 설정, 도구 호출을 단계적으로 연결한다.
- 에이전트가 필요한 기능을 순서에 맞게 선택하고 실행하도록 돕는다.
- 자동화 가능한 업무 수행을 목표로 한다.
- [[concepts/에이전트|에이전트]] 설계에서 프롬프트와 도구 실행 사이를 이어 주는 핵심 구조로 작동한다.

## 응용
워크 플로우는 에이전트가 사용자 요청을 분석한 뒤 지침 파일을 참고하고, 필요한 스킬이나 훅, 외부 도구를 호출해 결과를 생성하는 과정에 활용된다. 예를 들어 개발 보조 에이전트는 요청을 받은 뒤 [[entities/rules-md|rules-md]]나 [[entities/claude-md|claude-md]]의 지침을 적용하고, [[concepts/skills|skills]], [[concepts/hooks|hooks]], [[concepts/mcp|mcp]] 같은 실행 수단을 순차적으로 사용해 작업을 완료할 수 있다.
