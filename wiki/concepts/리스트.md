# 리스트

## 정의
리스트는 여러 데이터를 하나의 묶음으로 순서 있게 저장하고, 각 요소를 정해진 위치를 기준으로 조회하거나 조작할 수 있는 기본 자료구조이다.

## 주요 특징
- 데이터를 순차적으로 저장한다.
- 각 요소는 위치를 기준으로 접근할 수 있다.
- 여러 값을 하나의 구조 안에 묶어 관리할 수 있다.
- 크기를 유동적으로 바꿀 수 있는 자료구조로 설명된다.
- 데이터 관리와 코드 가독성을 높이는 데 사용된다.

## 응용
리스트는 여러 개의 값을 순서대로 저장해야 하는 상황에서 사용된다. 예를 들어 숫자, 문자열, 객체 등의 데이터를 한데 모아 반복 처리하거나, 특정 위치의 값을 조회하고, 필요한 요소를 추가·수정·삭제하는 방식으로 데이터를 관리할 수 있다.
