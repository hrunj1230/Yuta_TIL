# /resume

## 정의
/resume은 이전 대화나 중단된 세션의 맥락을 다시 불러와 작업을 이어가기 위한 세션 관리 명령이다. 에이전트 작업에서 장기 작업, 반복 작업, 과거 의사결정의 재사용이 필요한 경우 대화의 연속성을 확보하는 데 사용된다.

## 주요 특징
- 이전 대화 흐름이나 중단된 세션을 재개하는 명령이다.
- 기존 맥락을 다시 불러와 작업의 연속성을 유지한다.
- 장기 작업이나 반복 작업에서 과거 결정과 진행 상태를 재사용하는 데 유용하다.
- [[concepts/branch|branch]]가 세션을 복제하는 역할이라면, /resume은 기존 세션 맥락을 이어 받는 역할에 가깝다.
- [[concepts/btw|/btw]]가 별도 질문을 위한 복제 세션을 만드는 개념이라면, /resume은 기존 흐름으로 복귀하는 세션 관리 기능으로 볼 수 있다.

## 응용
- 중단된 에이전트 작업을 다시 시작할 때 사용한다.
- 이전 대화에서 정한 목표, 제약, 의사결정을 유지한 채 후속 작업을 진행할 때 활용한다.
- 장기간 이어지는 개발, 분석, 문서화 작업에서 작업 맥락을 보존하는 데 적합하다.
- 반복적으로 같은 프로젝트나 문제를 다룰 때 과거 대화의 맥락을 재사용하여 작업 효율을 높인다.
