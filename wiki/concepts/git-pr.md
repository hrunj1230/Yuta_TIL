# git pr

## 정의
git pr은 소스에서 정해진 포맷으로 생성할 수 있는 PR 작성 산출물로 언급되는 용어이다. 에이전트 환경에서는 [[concepts/skills|skills]]를 통해 반복적인 PR 작성 양식을 자동화하거나 표준화하는 맥락에서 사용된다.

## 주요 특징
- 개발 협업에서 변경 사항을 제안하고 설명하는 PR 문서 산출물과 관련된다.
- 정해진 포맷에 따라 생성될 수 있어 반복 작성과 표준화에 적합하다.
- [[concepts/skills|skills]]를 통해 단순 명령 실행을 넘어 협업 문서 작성까지 자동화할 수 있음을 보여준다.
- 진단이나 문제 해결 흐름이 코드 수정 제안 및 PR 작성까지 이어질 수 있음을 시사한다.
- [[concepts/에이전트|에이전트]]가 분석뿐 아니라 변경 제안과 문서화까지 수행하는 사례로 볼 수 있다.

## 응용
- 반복적인 PR 설명, 변경 요약, 테스트 결과, 체크리스트 작성 자동화
- 팀의 PR 템플릿이나 협업 규칙에 맞춘 문서 생성 표준화
- 문제 분석 이후 코드 수정 제안과 PR 작성까지 이어지는 개발 지원 흐름 구성
- [[concepts/진단-리포트|진단 리포트]]와 연결하여 분석 결과를 변경 제안 문서로 확장
