# 리스트 요소 조작

## 정의
리스트 요소 조작은 리스트에 담긴 값을 추가, 변경, 삭제하여 리스트의 내용을 동적으로 관리하는 기본 절차이다. 예를 들어 `append(5)`로 리스트 끝에 요소를 추가하고, `list[4] = 6`처럼 특정 인덱스에 새 값을 대입해 요소를 변경하며, `del list[3]`, `list.pop()`, `list.pop(0)` 등으로 요소를 삭제할 수 있다.

## 주요 특징
- 리스트의 크기와 내용을 실행 중에 유동적으로 바꿀 수 있게 한다.
- 요소 추가는 주로 `append()`를 사용해 리스트의 끝에 새 값을 넣는 방식으로 수행된다.
- 요소 변경은 특정 인덱스에 새 값을 다시 대입하여 수행된다.
- 요소 삭제는 `del`, `pop()` 등을 사용해 특정 위치, 마지막 요소, 첫 번째 요소 등을 제거할 수 있다.
- [[concepts/리스트|리스트]]의 인덱스 기반 구조를 전제로 하므로 [[concepts/리스트-조회|리스트-조회]]와 밀접하게 연결된다.

## 응용
리스트 요소 조작은 프로그램에서 데이터 목록을 실시간으로 관리할 때 사용된다. 예를 들어 사용자 입력값을 목록에 추가하거나, 잘못된 값을 수정하거나, 더 이상 필요하지 않은 항목을 제거하는 작업에 활용된다. 또한 반복 처리, 데이터 정리, 임시 저장소 관리 등 리스트를 사용하는 대부분의 프로그램 흐름에서 핵심적인 역할을 한다.
