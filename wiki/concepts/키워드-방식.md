# 키워드 방식

## 정의
키워드 방식은 입력이나 소스에 특정 단어가 포함되어 있는지만 확인해 기능 호출 여부를 결정하는 규칙 기반 접근이다. 소스에서는 이것이 [[concepts/skills|skills]] 자동호출의 실제 작동 방식이 아니라고 명시되며, 자동호출은 단순 키워드가 아니라 `skills.md`의 설명을 참조해 판단하는 방식으로 구분된다.

## 주요 특징
- 특정 단어의 존재 여부를 기준으로 기능 호출을 판단한다.
- 문맥, 의도, 설명 기반 의미 해석보다는 표면적인 문자열 일치에 의존한다.
- 구현은 단순하지만 복잡한 요청이나 암묵적 의도를 처리하는 데 한계가 있다.
- 소스에서는 [[concepts/자동호출|자동호출]]과 대비되는 방식으로 언급된다.
- 에이전트 기능 라우팅에서 설명 기반 판단의 필요성을 드러내는 비교 대상이다.

## 응용
- 단순 명령어 감지나 고정된 트리거 단어 기반 기능 실행에 사용할 수 있다.
- 초기 단계의 규칙 기반 라우팅이나 간단한 자동화 조건 설정에 활용될 수 있다.
- [[concepts/에이전트|에이전트]]의 기능 호출 방식이 문맥 기반인지 단순 문자열 기반인지 설명할 때 비교 기준으로 사용된다.
- [[concepts/skills|skills]] 자동호출이 단순 키워드 검색이 아니라 설명 기반 판단이라는 점을 설명하는 데 활용된다.
