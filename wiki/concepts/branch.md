# /branch

## 정의
/branch는 현재 대화 세션을 복제하여 기존 맥락을 보존한 별도의 대화 흐름을 만드는 명령어이다. 본세션의 흐름을 유지하면서 실험적 질문, 대안 탐색, 분기 작업을 수행할 수 있게 한다.

## 주요 특징
- 현재 세션의 맥락을 유지한 채 별도 세션을 생성한다.
- 본세션에 영향을 주지 않고 새로운 대화 흐름을 만들 수 있다.
- [[concepts/resume|/resume]], [[concepts/btw|/btw]]와 함께 세션 흐름을 관리하는 기능으로 설명된다.
- 짧은 질문이나 부가적인 확인을 복제 세션에서 처리하는 [[concepts/btw|/btw]]와 밀접하게 연결된다.
- [[concepts/에이전트|에이전트]]와의 대화에서 작업 맥락을 분리하거나 실험하는 데 유용하다.

## 응용
- 본 대화의 방향을 유지하면서 별도 아이디어를 시험할 때 사용한다.
- 기존 맥락을 바탕으로 여러 해결 경로를 비교할 때 활용한다.
- 본세션을 오염시키지 않고 짧은 부가 질문을 처리하는 흐름을 만들 때 사용한다.
- 긴 작업 중 특정 하위 문제를 독립적으로 탐색할 때 유용하다.
