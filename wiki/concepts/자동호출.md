# 자동호출

## 정의
자동호출은 사용자가 명령어를 직접 입력하지 않아도, 시스템이 요청의 맥락과 스킬 설명을 바탕으로 적절한 스킬을 선택해 호출하는 방식이다. 이는 단순한 키워드 일치가 아니라 설명 기반의 의미적 판단에 의존하는 호출 방법으로 설명된다.

## 주요 특징
- 사용자의 명시적 명령 입력 없이 시스템이 적절한 기능을 선택한다.
- 스킬의 설명 정보를 참조해 호출 여부를 판단한다.
- 단순 키워드 매칭보다 사용자의 의도와 맥락 해석이 중요하다.
- 에이전트가 필요한 기능을 능동적으로 실행하는 자동화 설계와 연결된다.
- 잘 작성된 스킬 설명이 자동 선택의 정확도에 직접적인 영향을 준다.

## 응용
자동호출은 사용자의 요청을 분석해 적절한 작업 도구나 스킬을 자동으로 실행해야 하는 에이전트 시스템에서 활용된다. 예를 들어 사용자가 자연어로 문제 해결, 문서 작성, 코드 분석 등을 요청하면 시스템이 해당 목적에 맞는 스킬을 선택해 실행할 수 있다. 이를 통해 사용자는 구체적인 명령어나 호출 형식을 기억하지 않아도 필요한 기능을 사용할 수 있다.
