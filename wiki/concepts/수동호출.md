# 수동호출

## 정의
수동호출은 사용자가 `/skills-name` 형태의 명령을 직접 입력하여 특정 [[concepts/skills|skills]]를 실행하는 방식이다. 시스템이 맥락을 판단해 호출 여부를 결정하는 방식과 달리, 사용자의 명시적 선택에 따라 기능이 실행된다.

## 주요 특징
- 사용자가 호출할 [[concepts/skills|skills]]를 직접 지정한다.
- `/skills-name`과 같은 명령 형식을 통해 실행된다.
- 호출 여부와 대상 선택의 제어권이 사용자에게 있다.
- 시스템이 설명이나 맥락을 해석해 자동으로 실행하는 [[concepts/자동호출|자동호출]]과 대비된다.
- 에이전트 기능 사용 방식에서 명시적 제어와 자동 판단을 구분하는 기준이 된다.

## 응용
수동호출은 사용자가 특정 기능을 확실히 실행해야 하는 상황에서 활용된다. 예를 들어 원하는 [[concepts/skills|skills]]가 명확하거나, 시스템의 자동 판단에 맡기지 않고 특정 작업 흐름을 직접 통제하려는 경우에 적합하다. 또한 여러 호출 방식이 공존하는 환경에서 사용자의 의도를 분명히 전달하는 방법으로 사용될 수 있다.
