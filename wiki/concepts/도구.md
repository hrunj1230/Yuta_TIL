# 도구

## 정의
도구는 에이전트가 실제 업무를 수행하거나 외부 시스템과 상호작용하기 위해 사용하는 실행 수단이다. 소스에서는 대화, 지침, [[concepts/워크-플로우|워크 플로우]] 다음에 위치하는 계층으로 제시되며, 프롬프트 기반 요청을 실질적인 자동화와 업무 처리로 전환하는 기능적 구성 요소를 의미한다.

## 주요 특징
- [[concepts/에이전트|에이전트]]가 실제 작업을 수행하도록 돕는 실행 계층이다.
- [[concepts/프롬프트|프롬프트]]와 지침에서 정의된 의도를 구체적인 행동으로 전환한다.
- [[concepts/skills|skills]], [[concepts/hooks|hooks]], [[concepts/mcp|mcp]] 같은 요소와 연결되어 역할 특화와 외부 시스템 연동을 가능하게 한다.
- 대화나 계획 자체가 아니라, 업무 처리와 자동화를 수행하는 기능적 구성 요소에 가깝다.
- 에이전트의 능력을 확장하고 반복 가능한 작업 수행을 지원한다.

## 응용
- 에이전트가 파일 조작, 코드 실행, 검색, 분석 등 실제 작업을 수행할 때 사용된다.
- [[concepts/mcp|mcp]]를 통해 외부 서비스나 시스템과 연결하는 데 활용된다.
- [[concepts/skills|skills]]를 통해 특정 업무 영역에 맞춘 실행 능력을 제공한다.
- [[concepts/hooks|hooks]]를 통해 특정 이벤트나 조건에 따라 자동화된 동작을 실행할 수 있다.
- 프롬프트 기반 요청을 워크 플로우와 결합해 자동화된 업무 처리 과정으로 구현하는 데 사용된다.
