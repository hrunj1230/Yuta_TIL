# 에이전트 특강 요약

## 출처
- 원본 파일: [[Today I Learn/2026_08_18.md]]
- 수집일: 2026-08-22

## 핵심 내용
이 문서는 [[concepts/에이전트|에이전트]] 기반 개발 환경과 업무 자동화 구성을 정리한 특강 메모이다. 핵심 흐름은 대화가 지침이 되고, 지침이 [[concepts/워크-플로우|워크 플로우]]로 구조화되며, 최종적으로 [[concepts/도구|도구]] 실행으로 이어지는 방식이다. [[concepts/프롬프트|프롬프트]]는 [[entities/rules-md|rules.md]]와 [[entities/claude-md|claude.md]] 같은 지침 파일을 거쳐 [[concepts/skills|skills]], [[concepts/hooks|hooks]], [[concepts/mcp|MCP]]로 확장된다. [[concepts/skills|skills]]는 정해진 형식의 작업을 수동 또는 자동으로 호출하고, [[concepts/hooks|hooks]]는 이벤트 발생 시 자동 줄맞춤 같은 반복 작업을 실행한다. [[concepts/mcp|MCP]]는 에이전트를 외부 시스템과 연결하며, [[entities/boost-mcp|boost-mcp]], [[entities/boost-kb|boost-kb]], [[entities/troubleshooter-mcp|troubleshooter-mcp]] 같은 사례로 업무 요약, 장애 분석, 코드 수정 제안까지 확장될 수 있음을 보여준다.

- [[entities/llm-wiki|llm-wiki]]: 에이전트가 활용할 수 있는 지식 기반 사례
- [[entities/아틀라스|아틀라스]]: 흩어진 저장소를 하나의 코드 지도로 정리하는 프로젝트
- [[entities/boost-mcp|boost-mcp]]: MCP 기반 업무 처리 및 요약 도구

- [[entities/viking|viking]]: 프롬프트 기반 앱 생성 서비스
- [[entities/troubleshooter-mcp|troubleshooter-mcp]]: 장애 분석과 코드 수정 PR 흐름을 지원하는 MCP 도구
- [[entities/langfuse|langfuse]]: 에이전트 평가 루프와 연결된 관찰·평가 도구

## 주요 사항
- 에이전트 기반 작업은 대화, 지침, 워크플로우, 도구의 계층으로 구성된다.
- [[concepts/skills|skills]]는 재사용 가능한 작업 단위이며, 수동 호출과 설명 기반 [[concepts/자동호출|자동호출]]을 모두 지원한다.
- [[concepts/hooks|hooks]]는 코드 수정 후 줄맞춤처럼 이벤트 기반 자동화를 담당한다.
- [[concepts/mcp|MCP]]는 에이전트와 외부 시스템을 연결하는 핵심 연결 계층이다.
- [[concepts/plugins|plugins]]는 skills, agent, hook, MCP를 팀에서 공유 가능한 설치·업데이트 단위로 묶는다.
- [[entities/아틀라스|아틀라스]]는 여러 저장소의 코드 흐름과 실제 API 스펙을 에이전트가 분석하도록 돕는 사례다.
- 에이전트 자동화가 확장되어도 [[concepts/헥사고날-아키텍쳐|헥사고날 아키텍쳐]], [[concepts/ddd|DDD]], [[concepts/레이어드-디자인패턴|레이어드 디자인패턴]] 같은 설계 지식은 여전히 중요하다.
