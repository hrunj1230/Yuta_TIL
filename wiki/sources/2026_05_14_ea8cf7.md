# 리스트와 함수 기초 학습 노트 - 요약

## 핵심 내용
이 학습 노트는 프로그래밍 입문 수준에서 [[concepts/리스트|리스트]]와 [[concepts/함수|함수]]의 기본 의미와 사용법을 정리한다. [[concepts/리스트|리스트]]는 데이터를 순차적으로 저장해 가독성과 관리 편의성을 높이는 자료구조로 설명되며, 순서가 있고 크기를 유동적으로 바꿀 수 있다는 점이 강조된다. 예시로 `list = [1,2,3,4]`가 제시되고, `list[0]`을 통해 첫 번째 요소를 확인하는 [[concepts/리스트-조회|리스트 조회]] 방식이 소개된다. 또한 `append`, 인덱스 대입, `del`, `pop()` 등을 활용한 [[concepts/리스트-요소-조작|리스트 요소 조작]] 방법이 정리되어 있다. 후반부에서는 [[concepts/함수|함수]]를 수학적 대응 관계와 정보통신 분야의 재사용 가능한 코드 묶음이라는 두 관점에서 설명하며, `def make_bread(a,b):` 예제로 함수 정의, 출력, 반환 구조를 보여준다.

## 주요 사항
- [[concepts/리스트|리스트]]는 순서가 있는 자료구조이며, 데이터를 순차적으로 저장해 관리하기 쉽게 만든다.
- [[concepts/리스트-조회|리스트 조회]]는 인덱스를 사용해 특정 위치의 요소를 확인하는 방식이다.
- [[concepts/리스트-요소-조작|리스트 요소 조작]]에는 추가, 변경, 삭제, 마지막 요소 삭제, 첫 번째 요소 삭제가 포함된다.
- [[concepts/함수|함수]]는 프로그래밍에서 재사용 가능한 코드 묶음이며, 매개변수와 반환값을 가질 수 있다.
