 접근 방법 비교
  1. Supervisor Pattern (추천) ⭐

  agent 완료 후 다시 router로 돌아가서 재평가                                                                                                                                                                   
  START → router → source_agent → router → embedding_agent → router → END
                        ↓                        ↓
                   source_tools            embedding_tools

  장점:
  - 자연스러운 agent 전환
  - 대화 흐름 유지
  - router가 전체 문맥 파악

  단점:
  - router를 매번 거쳐야 함 (약간의 오버헤드)

  2. Agent 간 Tool 호출

  각 agent가 다른 agent를 tool로 호출

  source_agent의 tools = [add_source, delete_source, call_embedding_agent]
  embedding_agent의 tools = [embed_source, call_source_agent]

  장점:
  - Agent가 직접 판단
  - 빠른 전환

  단점:
  - 순환 참조 위험
  - 복잡도 증가

  3. 통합 Agent + 모든 Tools

  하나의 agent가 모든 tool 보유
