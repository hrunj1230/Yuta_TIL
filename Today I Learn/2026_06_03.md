## LLM devops agent 
장애대응을 ai 에이전트를 이용해서 장애의 상황가 규모를 판단해서 빠른시간에 알려줄 수 있도록 활용했다

장애의 알람 -> trigger 서버 -> devops agent 
로 넘어가게 되고 
devops agnet 내부에서도
1.preprocessor ( 장애 알람을 가공 전달)
2.ic agent (여러 subagent로 가공된 알람을 각각의 에이전트에 전달하고 종합하는 메인 에이전트 역할)
	nx agent (서버의 상태 파악)
	prs agent (prs서버 상태 파악)
	seer agent(infra 상태 파악)
	env agent (외부 간섭 상태 파악)
3.summarizer (ic 가 통합한 subagent의 리포트를 llm을 통해 분석)
python / Go
openAi agent sdk
openai dashboard
trigger queue - 동일 시점 알람에 대해 묶어서 처리
