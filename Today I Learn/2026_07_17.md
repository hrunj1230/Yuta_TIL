## 💡 오늘 배운 것

### 1.알고리즘(python-객체참조/ 최대공약수-gcd)
#### 내용
- python에서의 포인터가 아닌이유 int == immutable (불변객체) 이다.그래서 새로운 int를 만들어서 참조한다.
- 근데 list에서 추가나 수정으로는 바뀌는 이유는 mutable(가변객체)이다.그래서 리스트는 객체 자체를 수정할수있다.
- 파이썬의 모든 변수는 객체에 대한 참조를 가지고 있다.

#### 예제
```language
a = 1
b = a
b = 3 
print(a) = 1
a ->1
b ->1
b ->3 (int 3의 객체를 새로 생성해서 참조)
a ->3 x
```
