devops - 개발과 운영의 협업을 통해 소프트웨어 배포 속도와 안정성을 높이는 문화 및 방법론

EC2 - 가상서버(인스턴스)를 생성,구성,관리할 수 있도록 하여 다양한 워크로드를 지원하는 확장 가능하고 안전한 클라우드 컴퓨팅 서비스

빅뱅 배포 - 기능이나 변경사항을 한꺼번에 운영 환경에 배포하는 방식

docker - 애플리케이션이 실행되는 데 필요한 요소(코드,라이브러리,설정 등)를 하나로 묶어 어떤 컴퓨터에서든 동일하게 실행되도록 도와주는 도구

docker file - 도커이미지를 생성하기 위한 명령어 및 설정이 담긴 스크립트 파일

docker image - 애플리케이션 실행에 필요한 세팅의 읽기 전용 스냅샷

docker container - 애플리케이션과 그 실행에 필요한 모든 종속성을 포함하여 경략화되고 독립적으로 실행되는단위

volume - 컨테이너 간 데이터 공유 및 영속성을 제공하기 위해 호스트 파일 시스템에 생성되는 독립적인 저장소 (컨테이너의 비영속적인 속성을 해결하기 위한 데이터 저장소)

bridge network - 컨테이너들이 동일한 호스트 내에서 서로 통신할 수 있도록 연결해주는 도커의 기본 가상 네트워크 ( fe - be - db - cash ..)

docker compose - 여러 컨테이너로 구성된 애플리케이션을 YAML형식의 파일로 명확하게 정의하고,단일 명령어로 동시에 실행 및 관리 할 수 있도록 지원하는 Docker의 공식 오픈소스 도구

CI - 개발자가 작성한 코드를 자동으로 통합(builed) 및 테스트하여 코드의 품질을 지속적으로 유지하는 개발하는 프로세스

CD - 코드가 자동화된 테스트를 통과하면 운영 환경까지 자동으로 배포되는 소프트웨어 배포 프로세스

github actions - github 내에서 코드 빌드, 테스트, 배포 등의 워크플로우를 자동화하는 CI/CD도구 code push → git ci → git cd → aws ec2
