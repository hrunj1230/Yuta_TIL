경험을 통해 자동으로 개선하는 컴퓨터 알고리즘의 연구 분야

### Random Forest
의사 결정 트리 기반의 앙상블 학습 기법으로 다수의 트리를 결합하여 예측 성능을 향상시키는 모델
앙상블 -> 여러개의 예측 모델을 결합하여 높은 예측 성능을 얻는 기법
### K-NN(Nearest Neighbors)
새로운 데이터를 가장 가까운 K개의 이웃과 비교하여 분류하거나 예측하는 알고리즘
유클리디안 거리(두점사이 직선의 최단거리)나 맨허튼 거리(좌표축을 따라 이동하는 거리 x축 + y축)를 사용

### SVM(Support Vector Machine)
주어진 데이터를 최적으로 분리하는 초평면(Hyperplane)을 찾는 지도 학습 알고리즘

### Naive Bayes
모든 특성이 서로 독립이라고 가정하고 베이즈 정리를 활용하여 확률을 계산하는 분류모델
(한 특성의 값이 다른 특성의 값에 영향을 주지 않는다고 가정)
